# Learned rules

You write these, not Claude. CLAUDE.md imports this file, so everything here loads into every
session and applies to every script and every prompt.

**How to use it:** every time you reject something, add one line saying what to avoid and why.
Every time you approve something that is genuinely good, add what to prefer. One line each.

This is the only part of the system that makes the output better. The rest only makes it faster.
